# 사회적 고립 위험 AI 에이전트 — 데이터 소스 및 지표 설계 노트

> 2026 빅콘테스트 AI데이터활용 분야 「사회적 고립 예방 및 대응을 위한 AI 에이전트 모델 개발」 준비 과정에서 나온 조사·브레인스토밍 내용을 정리한 문서. 대회 제공 데이터(통신·카드, '25.7~12월, 강남구·춘천시)만으로는 고립 위험 판단에 한계가 있다는 문제의식에서 출발해, 보강할 외부 데이터와 지수 설계 방향을 다룬다.

## 1. 배경: 왜 강남구·춘천시인가

공식 근거는 찾지 못했지만(bigcontest.or.kr에 지역 선정 사유는 공개되어 있지 않음), 조사 과정에서 나온 단서는 다음과 같다.

- **강남구**: SK텔레콤과 강남구청이 2019년부터 운영해온 "독거어르신 ICT돌봄서비스(NUGU)" — AI스피커를 독거노인 가정에 보급해 안부 확인·SOS 알림을 제공하는 사업. 최근 AI 돌봄기기를 1,240대까지 확대 운영 중. SK텔레콤 본사도 강남 소재.
- **춘천시**: 국토교통부 "스마트시티 챌린지 사업"의 예비사업지로 2019년·2021년 두 차례 선정된 이력. 통신사 주도 사업이라기보다 정부 주도 스마트시티 인프라 시범도시에 가까움.
- **데이터 제공사 확인**: bigcontest.or.kr 공식 페이지에서 2026년 AI데이터분석/활용 분야 모두 **"데이터제공: SK텔레콤, 신한카드"**로 명시됨. 2024년(12회) 대회 공지사항에서도 SKT·신한카드가 데이터 제공사로 등장 — 두 회사가 최근 대회에서 반복적으로 데이터를 제공해온 고정 파트너로 추정됨.
- **작년(13회, 2025) 자료와의 비교는 확인 실패**: 2025년 AI데이터활용 분야 주제는 "가맹점별 찰떡 마케팅 전략을 찾아라"(소상공인 마케팅)로 올해와 전혀 다른 주제였음. bigcontest.or.kr의 지난 대회 게시판은 12회(2024)까지만 열람 가능했고, 13회(2025) 아카이브나 지역명 언급 여부는 사이트에서 확인하지 못함. 필요 시 운영사무국(bigcontest@kait.or.kr) 문의 필요.

## 2. 문제의식: 제공 데이터의 한계

- 기간이 '25.7월~12월 6개월로 짧아 계절성·장기추세 파악에 제약
- 통신(유동인구)·카드(결제) 데이터만으로는 "고립"이라는 사회적 상태를 직접 관측하기 어렵고, 행동 변화의 간접 프록시에 그침
- → **인구구조 데이터 + 행정 복지데이터 + 기존 고립탐지 사례의 지표 설계를 결합**해서 보강 필요

| 소스 | 제공 항목 | 비고 |
|---|---|---|

**주요 발견 — 가설 수정 필요**: 애초 "강남=청년형 고립 / 춘천=고령형 고립"이라는 대비 구도를 가정했으나, 강원일보 보도에 따르면 **춘천시 청년(20~30대) 1인가구 비율이 강원도 내 최고치인 45.4%**로 나타남(강원대·한림대 대학가 영향으로 추정). 즉 춘천도 강남 못지않게 청년 1인가구 비중이 크고, 고령 독거와 청년 자취가 공존하는 이중구조일 가능성이 높음. → KOSIS/행안부 데이터를 실제로 받아 두 지역의 연령대별 1인가구 분포를 직접 비교·검증하는 작업이 다음 단계로 필요.

## 4. 참고할 만한 국내 기존 사례

### 4-1. 서울시 AI/IoT 기반 고립 위험가구 탐지
- **'똑똑안부확인'**: 휴대전화 사용량·걸음수 측정 앱 + IoT 디바이스(문열림센서, 스마트플러그)
- **'AI 안부든든'**: 휴대폰 데이터 + 전력 사용량 기본 모니터링, 휴대폰 충전·잠금장치 사용이력 자동 조사
- 공통 로직: "움직임/사용량이 감지되지 않는 이상 상황" 발생 시 담당자 출동
- → 대회의 유동인구(이동 여부) 데이터와 설계 철학이 동일. **"활동량의 급격한 감소·이상치 탐지"**를 위험 신호 정의의 핵심 축으로 삼을 수 있음

### 4-2. 보건복지부·사회보장정보원 「복지 사각지대 발굴 시스템」
- 위기정보 44종(2024년 39종에서 확대) 결합 스코어링
- 확인된 항목: 단전, 단수, 건강보험료 체납, 통신비 체납, 수도요금 체납, 가스요금 체납, 재난적 의료비 지원대상, 채무조정 중지자, 고용위기 등 (전체 44종 목록은 비공개 — 필요 시 보건복지부 044-202-3009 문의)
- → "돈이 흘러야 할 곳에서 흐르지 않는 패턴"을 위기 신호로 보는 접근. 카드 결제 급감, 특정 업종(병원·마트 등) 결제 중단 패턴에 유사하게 적용 가능

### 4-3. 통계·실태조사 (검증/벤치마크용)
- KOSIS 「고독사 발생현황: 지역별」(`DT_117111_A001`) — 보건복지부 2024년 고독사 실태조사 기반. 여러분이 만들 위험지수의 **타당성 검증(ground truth)** 자료로 활용 가능
- 서울시 고립은둔청년 실태조사 (서울 열린데이터광장, `OA-22347`) — 벤치마크 수치 참고용
- 학술 척도(UCLA Loneliness Scale, De Jong Gierveld Scale 등) — 설문 기반이라 직접 활용은 어렵지만 "고립"이라는 구성개념 정의에 참고 가능

## 6. 지수 생성 방법론 아이디어

1. **정규화 + 가중합 (전통적 방식)**: 지표별 min-max 또는 z-score 정규화 후 도메인 지식 기반 가중치로 합산. 해석이 쉽고 심사 발표 시 설명하기 용이
2. **지도학습 기반 스코어링**: 고독사 실태조사·위기가구 발굴 실적 등을 타깃 라벨로 삼아 XGBoost 등으로 위험도 예측. "AI 에이전트"라는 대회 취지에 부합하지만, 지역·기간이 안 맞는 라벨 데이터의 희소성이 한계
3. **비지도 이상탐지 (절충안)**: Isolation Forest 등으로 "평소 활동 패턴 대비 이탈도"를 스코어화. 서울시 '안부확인' 서비스의 실제 탐지 로직과 결이 일치
4. 대회 예시(5단계 실시간 지수화)를 따르려면 위 스코어를 분위수(quintile) 기준으로 5단계 구간화하는 방식이 실무적으로 흔히 쓰임
