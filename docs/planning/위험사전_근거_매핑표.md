## 0. 이 표를 읽는 법

설문 **응답**(점수)에서 키워드를 뽑지 않는다. 자료마다 역할이 다르다.

| 자료 | 이 표에서 하는 일 |
|---|---|
| 설문 **문항** (S1~S4) | 태그가 **무엇을 뜻하는지** 정의하는 근거 |
| 실태조사 **정의·결과** (S5·S6) | 태그가 **왜 필요한지**, 심각도를 어떻게 매길지의 근거 |
| 키워드(표현) | 문항의 개념을 **청년이 채팅에서 쓸 말투로 바꿔 쓴 것** — 다음 단계(②)에서 작성 |

- 문항은 **번호 + 주제 요약**만 적는다. 원문은 옮기지 않는다(척도 이용 조건 — S1은 "연구자용으로 제공"이라고 명시).
- 근거 강도: **강** = 문항·정의가 태그 개념과 직접 일치 / **중** = 일부 겹치거나 간접 근거 / **약** = 직접 근거 없음, 보강 필요

**기본 심각도를 정한 방식(안)**
- **0.3** 생활 여건 신호(생계부담) — 그 자체로는 고립이 아님
- **0.4** 관계·정서 신호의 가벼운 단계(소외감·무기력·장기구직)
- **0.5** 관계의 핵심 결핍 또는 회피 행동(대화상대없음·사회적회피) — S4에서 정서적 외로움이 친밀한 관계의 부재로 정의되고, S5 은둔 정의가 외출 회피를 핵심으로 둠
- **0.6** 지속·포기 신호(고립지속·구직단념) — S5 정의의 "6개월 이상", "구직 활동 없음"에 해당
- **0.8** 장기화 신호(장기고립) — S5·S6에서 장기화 비율이 높고 재고립이 잦음
- 실태조사 **비율은 태그를 넣는 이유**로만 쓰고 심각도 숫자로 바로 바꾸지 않는다(집단 비율이 개인 발화의 위험도를 뜻하지는 않음)

## 3. 발화 하나의 키워드 점수 K (안)

설계 문서 8-3절 `severity = 0.5·K + 0.5·T + 지속성`의 K를 계산하는 규칙이다.

| 규칙 | 내용 | 근거 |
|---|---|---|
| 기본 | K = 걸린 태그들의 기본 심각도 중 **최댓값** | 지금 대본과 같은 방식(대화 1회 심각도 = 최댓값) |
| 여러 태그 | 서로 다른 태그가 더 걸리면 태그 하나당 **+0.05** (최대 1.0) | 여러 차원이 겹치면 더 심각(S4: 정서·사회 두 차원) |
| 기간 표현 | "몇 달째·계속·맨날" → `고립지속` 태그 추가 / "1년 넘게·몇 년째" → `장기고립` 태그 추가 | S5 "6개월 이상" 기준 |
| 완화 표현 | "오늘·방금·요즘 좀·가끔" 같은 일시적 표현만 있으면 **−0.1** | 일시적 상태는 고립 정의에 들지 않음(S5) |
| 관용·과장 | v1은 처리하지 않음(예외 목록만). LLM `idiom_flag`로 루미 단계에서 보정 | 설계 문서 8-3 |

**지금 대본 값과 비교** (위 규칙을 적용하면)

| 대본 선택지 태그 | 지금 | 규칙 적용 |
|---|---|---|
| 무기력 | 0.4 | 0.4 |
| 생계부담 | 0.3 | 0.3 |
| 사회적회피 | 0.6 | 0.5 |
| 고립지속 | 0.7 | 0.6 |
| 대화상대없음 + 소외감 | 0.6 | 0.55 |
| 장기구직 + 무기력 | 0.6 | 0.45 |
| 구직단념 + 사회적회피 | 0.7 | 0.65 |
| 고립지속 + 장기고립 | 0.8 | 0.85 |

차이가 큰 곳은 `장기구직 + 무기력`(0.6 → 0.45)이다. 장기구직의 근거 강도가 "중"이라 낮아졌다 — 킥오프에서 그대로 갈지 정한다.
대본 값을 바꾸면 위험 탐지의 미시 신호가 조금 달라지므로, 바꾼 뒤 `risk_agent/validate.py`를 다시 돌린다.
