## 0. 이 표를 읽는 법

설문 **응답**(점수)에서 키워드를 뽑지 않는다. 자료마다 역할이 다르다.

| 자료 | 이 표에서 하는 일 |
|---|---|
| 외로움 척도 **문항** (S1~S4) | 태그가 **무엇을 뜻하는지** 정의하는 근거 |
| 실태조사 **판별 기준** (S5-a·S6) | 태그가 **공식 고립·은둔 정의의 어느 조건**에 해당하는지 |
| 실태조사 **결과·국가지표** (S5·S6·S8·S9) | 태그가 **왜 필요한지**, 심각도를 어떻게 매길지의 근거 |
| 키워드(표현) | 문항의 개념을 **청년이 채팅에서 쓸 말투로 바꿔 쓴 것** — 다음 단계(②)에서 작성 |

- 문항은 **번호 + 주제 요약**만 적는다. 원문은 옮기지 않는다(척도 이용 조건 — S1은 "연구자용으로 제공"이라고 명시).
- 근거 강도: **강** = 문항·정의가 태그 개념과 직접 일치 / **중** = 일부 겹치거나 간접 근거 / **약** = 직접 근거 없음, 보강 필요
- 실태조사 **비율은 태그를 넣는 이유**로만 쓰고 심각도 숫자로 바로 바꾸지 않는다(집단 비율이 개인 발화의 위험도를 뜻하지는 않음).

- **무기력 약 → 중**: 우울 척도(진단 도구) 없이도 실태조사의 유형 분류(의존형)·번아웃 문항·생활 리듬 붕괴로 설명 가능. → **우울 척도는 쓰지 않는 쪽을 권장**(4절 참조).
- **생계부담 약 → 중**: "돈 걱정" 자체는 고립이 아니지만, 공식 판별 기준(G-E3)과 국가지표(S8)가 **"돈을 빌릴 사람이 없음"을 고립의 한 축**으로 본다. → 표현 작성 시 "돈이 없다"(0.3)보다 "**돈 빌릴 데도 없다**"를 생계부담 + 대화상대없음 조합으로 잡는 방안 검토.

**기본 심각도를 정한 방식(안)** — 변경 없음
- **0.3** 생활 여건 신호(생계부담) — 그 자체로는 고립이 아님
- **0.4** 관계·정서 신호의 가벼운 단계(소외감·무기력·장기구직)
- **0.5** 관계의 핵심 결핍 또는 회피 행동(대화상대없음·사회적회피) — S4에서 정서적 외로움이 친밀한 관계의 부재로 정의되고, S5-a 은둔 기준이 외출 회피를 핵심으로 둠
- **0.6** 지속·포기 신호(고립지속·구직단념) — S5-a의 "6개월 이상", "구직 활동 없음"에 해당
- **0.8** 장기화 신호(장기고립) — S5·S6에서 장기화 비율이 높고 재고립이 잦음

## 3. 점수 규칙 (2026-10-08 확정)

`소셜월드_게임흐름_NPC_설계.md` 8-3절의 심각도 공식에 들어가는 키워드 점수 K, 기간 표현, 지속성, 구간을 정한다. 킥오프 결정 기록은 `위험사전_v1_작업계획.md` 6절.
기존 코드 `social_world/common/npc/severity.js`·`severity_config.json`은 10/7 이전 규칙이다 — Python 판단 서버로 옮기면서 이 절대로 고친다.

### 3-1. 문장 하나의 키워드 점수 K

| 규칙 | 내용 | 근거 |
|---|---|---|
| 기본 | K = 걸린 태그들의 기본 심각도 중 **최댓값** | 가벼운 단어가 여러 개라고 무거워지지 않게(합산하지 않음) |
| 차원 가산 | 최댓값 태그와 **다른 차원**의 태그가 있으면 차원 하나당 **+0.1, 최대 +0.2**. 같은 차원끼리는 가산 없음 | 여러 측면이 겹치면 더 심각(S4: 정서·사회 두 차원). 같은 사실을 두 번 세지 않게 |
| 기간 표현 | 3-2 표대로 태그를 붙인다. 기간 태그는 **하나만**(긴 쪽) | S5-a "6개월 이상", 장기고립 "1년 이상" |
| 완화 표현 | "오늘·어제·며칠·요즘 좀·가끔"만 있고 기간 태그가 없으면 **−0.1** | 일시적 상태는 고립 정의에 들지 않음(S5-a D) |
| 관용·과장 | LLM `idiom_flag`면 K × 0.5 | `소셜월드_게임흐름_NPC_설계.md` 8-3 |
| 상한 | K ≤ 1.0 | — |

**차원** (2절의 차원 칸을 가산 계산용으로 묶은 것)

| 차원 | 태그 |
|---|---|
| 정서 | 대화상대없음, 무기력 |
| 사회 | 소외감 |
| 행동 | 사회적회피 |
| 경제 | 장기구직, 구직단념, 생계부담 (구직단념은 2절에서 경제·행동이지만 가산에서는 경제로 센다) |
| 지속 | 고립지속, 장기고립 |

**예시**

| 문장 | 태그(차원) | K |
|---|---|---|
| "1년 넘게 집에만 있고, 얘기할 사람도 없고, 일자리도 포기했어" | 장기고립(지속)·사회적회피(행동)·대화상대없음(정서)·구직단념(경제) | 0.8 + 0.2 = **1.0** |
| "1년 넘게 집에만 있어" | 장기고립(지속)·사회적회피(행동) | 0.8 + 0.1 = **0.9** |
| "돈도 없고 얘기할 사람도 없고 다 하기 싫어" | 생계부담(경제)·대화상대없음(정서)·무기력(정서) | 0.5 + 0.1 = **0.6** |
| "얘기할 사람도 없고 다 하기 싫어" | 대화상대없음·무기력(같은 정서) | **0.5** |
| "요즘 좀 지치고 힘들어" | 무기력 + 완화 | 0.4 − 0.1 = **0.3** |

### 3-2. 기간 표현

| 기간 표현 | 처리 |
|---|---|
| 오늘·어제·며칠·요즘 좀·가끔 | 일시적 → K −0.1 |
| 몇 주·한 달쯤 | 기간 태그 없음(본래 태그만) |
| 몇 달째·반년·계속·맨날 | **고립지속(0.6)** |
| 1년 넘게·몇 년째 | **장기고립(0.8)** — 고립지속은 같이 붙이지 않음 |

### 3-3. 심각도·지속성·구간

```
severity = min(1, 0.5·K + 0.5·T + 지속성)          T = LLM 톤 점수(0~1)
지속성 = 그 세션에서 위험 태그가 붙은 발화의 순번 기준 — 1~2번째 0 / 3~4번째 +0.1 / 5번째부터 +0.2
위기 판정(작업계획 6-1 ①) → 1.0
```

| 구간 | 루미의 대응 |
|---|---|
| < 0.45 | 일반 대화 |
| 0.45 ~ 0.8 | 공감 + 하루·전문 상담 창구를 부드럽게 제안 — **세션당 1번**(거절하면 그 세션에서 다시 안 함) |
| ≥ 0.8, 위기 아님 | **강한 연결 제안** — 1577-0199(정신건강 위기상담), 하루 |
| 위기 판정 | 109·1577-0199 고정 안내 + `report_crisis()`(세션당 1번 기록), 대화는 계속 |

- 지속성 예: 같은 말("기운이 없어")을 반복해도, 다른 말("기운 없어" → "얘기할 사람도 없고" → "밖에도 안 나가")이 이어져도 3번째 위험 발화부터 +0.1, 5번째부터 +0.2
- 세션 결과는 최고 심각도 하나만 저장한다(`npc_sessions.severity_score`). 구간 기준 변경(0.5 → 0.45)은 루미의 대응만 바꾸고 저장되는 숫자 척도는 바꾸지 않는다

### 3-4. 위기 판정과의 관계

위기는 K와 별개로 위기 표현 사전이 먼저 판정한다 — `strong` 즉시 위기, `ambiguous`는 LLM이 맥락으로 확인(실패·시간 초과면 위기), `idiom`은 위기 아님(작업계획 6-1 ①). 고립 점수가 아무리 높아도 위기 표현이 없으면 109를 안내하지 않는다.

### 3-5. 루미 대본 선택지와 새 규칙

| 대본 선택지 | 지금 태그 · 점수 | 새 규칙 태그 | K |
|---|---|---|---|
| 생활비 지원 제도를 알고 싶어요 | 생계부담 · 0.3 | 생계부담 | 0.3 |
| 오래 준비했는데 계속 떨어져서 지쳤어요 | 장기구직+무기력 · 0.6 | 장기구직(경제)+무기력(정서) | 0.5 |
| 요즘은 아예 아무것도 하기 싫어요 | 구직단념+사회적회피 · 0.7 | 구직단념(경제)+사회적회피(행동) | 0.7 |
| 요즘 좀 지치고 힘들어 | 무기력 · 0.4 | 무기력 + 완화 | 0.3 |
| 속얘기할 사람이 별로 없어 | 대화상대없음+소외감 · 0.6 | 대화상대없음(정서)+소외감(사회) | 0.6 |
| 다 귀찮고 혼자 있는 게 편해 | 사회적회피 · 0.6 | 사회적회피 | 0.5 |
| 몇 주 됐어 | 고립지속 · 0.7 | 기간 태그 없음(앞 선택지 태그만) | — |
| 몇 달째야 | 고립지속+장기고립 · 0.8 | 고립지속 | 0.6 |
| (추가 제안) 1년 넘었어 | — | 장기고립 | 0.8 |
| 사실 다 그만두고 싶을 때가 있어 | 위기발화 · 1.0 | 위기(`strong`) | 1.0 |

대본에는 LLM 톤 T가 없으므로, 대본 심각도를 K만으로 둘지 선택지마다 T를 정해 둘지는 아직 정하지 않았다(작업계획 6-2). 대본 값을 바꾸면 위험 탐지의 미시 신호가 달라지므로 바꾼 뒤 `risk_agent/validate.py`를 다시 돌린다.
