## 3. 확정된 핵심 설계 (왜 이렇게 했나)

### 3-1. 데이터 제약과 활용 전략
- **통신 = 배경지표(baseline)**, **카드 = 트리거(trigger)**. 통신은 월 6점뿐이라 일별 이상탐지 불가, 카드는 184일 일별. 변동성 2.3배 차이.
- 통신의 연령성별·시간대·요일 테이블은 서로 조합 불가 → "20대 여성의 심야 유동" 같은 지표는 원천 불가.
- **거시·미시 2층**: 거시(대회 데이터, 비식별 집계)는 "어디·누가 위험한가", 미시(소셜 월드 대화, 익명 집계)는 "왜·무엇이 필요한가". 대회 데이터엔 텍스트도 개인도 없으므로 미시는 독립 신호원.
- 가상데이터(synthetic)는 대회 규칙상 허용, 단 **생성 방식 설명자료 제출 필수** → 작성 완료.

### 3-2. EDA 결론 → 지표 설계 원칙 (`데이터_분석근거_정리.md` 9장)
1. 정규화 필수(코호트 규모 격차 최대 1,400배) 2. 요일 보정 필수(~24%p) 3. 공통 성분 제거(원거리 코호트 리듬 상관 0.847)
4. 명절은 총량보다 **구성**을 바꾼다(춘천 추석 총량 +2.4%인데 업종 구성 대격변) 5. 업종 지표는 추세가 아니라 **이벤트 반응도**로
6. 통신=배경, 카드=신호 7. baseline에서 연휴 제외 8. 거주여부는 금액·건수 기준으로만
9. **건수 기반 + 고정지출(세금·보험·통신요금·등록금 등) 제외** — 금액은 세금공과금(금액 28%)에 지배됨
10. **코호트 간 비교보다 코호트 내 시간 변화** — 연령 교란 잔존

가설: **H-A** 이벤트 무반응형 / **H-B** 필수소비 편중(선택소비 위축)형 / **H-C** 구조적 저활동형.

### 3-3. 위험 지수 (현재 구현, 잠정안 — `risk_agent/config.py`)
- 탐지: 요일 중앙값 보정 → 29일 이동중앙값 추세 제거 → MAD robust z(임계 3.5)
- 입력 4개(모두 "클수록 위험"): `baseline_z`(통신 6개월 추세 하락) · `trigger_z`(카드 eval이 baseline보다 낮은 정도) · `event_response`(명절 반응이 동료 코호트보다 약한 정도, H-A) · `micro_signal`(심리상담 키워드율·심각도, 월 5세션 미만이면 null)
- 가중치: 통신 0.20 · 카드 0.30 · 이벤트 0.30 · 미시 0.20 (미시 없으면 0.25/0.375/0.375) — "거시 주, 미시 보정"
- 등급: 분위수 5단계 + 미시 z≥2.0이면 최소 Lv.3
- 원인 분해: 가중치×(부분점수−50) 초과기여. 3점 미만이면 "뚜렷한 원인 없음" → 자원 매칭 대신 "검증 먼저" 제안
- 실제 청년 모드 입력: 카드 `cnt_ex_fixed`(고정지출 제외 건수), 통신 `flow_pop_monthly`

### 3-4. 소셜 월드·안전·개인정보 (구현 기준안, 팀 확정 전)
- NPC 3종(정책추천·취업상담·심리상담)은 **대본형**. 선택지마다 위험 키워드 태그(10종: 무기력·소외감·대화상대없음·장기구직·구직단념·사회적회피·생계부담·고립지속·장기고립·위기발화)와 0~1 심각도. 태그는 UCLA 외로움 척도·De Jong Gierveld·서울시 고립은둔청년 실태조사 문항 주제에서 가져옴.
- **대화 원문 저장 안 함**. `npc_sessions`(본인만 RLS) → DB 함수 `aggregate_npc_sessions()` → `npc_chat_metrics`(코호트×월, user_id 없음, 브라우저 차단) → 에이전트가 secret key로 읽음.
- **k-익명성 k=5**: 미달 코호트는 미시신호 null, 대시보드 키워드 숨김.
- **위기**: 위기 선택지 → 109·1577-0199·112/119 즉시 안내 + `report_crisis()`로 지역·시각·NPC만 `escalations`에 기록(user_id 없음) → 대시보드 상단 알림.
- **환류**: `cohort_feedback`에 코호트별 추천 NPC·미션만. **위험 등급·점수는 시민 화면에 절대 전달하지 않음.**
- 심리상담 NPC는 "상담사가 아니라 스크리닝·연결 도구"로 고지.
- 서비스 대상은 청년(20~30대), **탐지 범위는 전 연령 유지**(고령 신호는 기존 오프라인 돌봄으로 분기).

### 3-5. 기술 스택
- 전처리·에이전트: Python 3.12, pandas 2.1+, numpy 1.26+
- 프론트: React(확정). 렌더링 2D/2.5D/3D는 **미정**(현재 React 2D)

| 소셜 월드 화면 | 4 | 1 | 2 | 광장·미션방·동아리방. 미니게임·게시판 없음 |
| 안전·개인정보·환류 | 4 | 0 | 0 | 위기 안내·k-익명성·고지·환류(대본 기준) |

**검증 결과(합성)**: 원형 6/6 탐지, 원인 6/6 일치, Lv.5 중 실제 원형 3/5, **정상 18개 중 8개 오탐**(분위수 구조 한계). 내적 타당성만 보여준다.

**실제 청년 결과**: 8개 코호트 입력 z 모두 ±1.5 이내 → 뚜렷한 이탈 없음. `detect_youth.py`도 위축 후보 0건. 춘천 30대 eval 건수 −7%는 계절(11~12월 추위) 영향 가능.

## 6. 알려진 한계 (보고서에 그대로 명시할 것)

- 분위수 등급은 위험이 없어도 상위 20%를 "위험"으로 만든다 → 오탐. 절대 임계값 병행 또는 "두 주기 연속 Lv.3+" 안정성 조건 필요.
- 실제 청년 데이터에서 고립 신호 없음 → **"왜 청년인가"의 데이터 근거가 아직 없다.**
- 거시(2025 하반기)와 미시(현재) 시점 불일치.
- 미시 신호는 시연용(합성 배경으로 k=5 충족). 원형 효과 크기는 가정값.
- 환류가 분위수 등급을 따라 상위 코호트 5/8에 적용됨 — 등급 방식 한계가 개인화로 전파.
- 구조적 한계: 개인 관측 불가(생태학적 오류 주의), 통신 축 교차 불가, 카드 오프라인 한정, 고객 거주지 시도 단위.

## 8. 이어받는 사람(AI 포함)이 지킬 규칙

**코드**
- `DATA/`는 읽기 전용. 통신 로딩의 `drop_duplicates()` 제거 금지(12월 파일 완전중복 → 수치 2배).

- 관리자 대시보드 HTML은 외부 공개 금지.
