## 4. 알려진 한계 (보고서에 그대로 쓸 것)

- **분위수 등급의 오탐**: 합성 데이터에서 정상 18개 중 8개가 Lv.3 이상. 원인 없는 코호트는 "뚜렷한 원인 없음"으로 표시하고 자원을 매칭하지 않지만, 실서비스라면 두 주기 연속 확인 같은 안정성 조건이 필요
- **실제 청년 데이터에서는 뚜렷한 이탈 없음**: 8개 코호트 모두 z가 ±1.5 안. 그래도 분위수라 2개가 "위험"으로 나온다 → 고립 발견으로 보고하면 안 됨(전처리 쪽 "위축 후보 0건"과 일치)
- **미시 신호는 시연용**: 실제 이용자가 적어 합성 배경(`source='synthetic'`)을 깔아 k=5를 채웠다
- **원형 효과 크기는 가정값**: 합성 검증은 내적 타당성만 보여준다
