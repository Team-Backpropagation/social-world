# EXP-003 — 이음 마을 Showcase UI/UX v0.2

**개인 시제품 / 팀 미확정.** 원본 컨셉 이미지는 구도와 분위기 참고로 사용했다. 실제 AI 상담·기관 서비스·지역 데이터는 연결되지 않았다.

이 화면은 기존 디자인 실험안으로 보존한다. 첨부 이미지 구도를 충실히 보여 주는 별도 [EXP-004 시제품](../exp004/README.md)이 새 디자인 실험이다.

## 바로 보기

[단독 HTML 시제품](showcase-uiux-prototype.html)은 한 파일에 CSS와 JavaScript가 포함되어 있다. 파일을 브라우저에서 열어 조작할 수 있게 만들었으나, 이 작업 환경의 브라우저 자동화는 `file:` 접근을 차단해 직접 실행 확인은 못 했다.

개발 서버로 보는 방법:

```powershell
cd experiments/exp003/social_world/react_app
npm ci --offline
npm run dev -- --host 127.0.0.1
```

`http://127.0.0.1:5173/` 또는 `/showcase`를 연다. 패키지 캐시가 없으면 일반 `npm ci`를 사용한다. 단독 HTML을 다시 생성하려면 `npm run build:standalone`을 실행한다.

## 시연 순서

1. 내 방에서 **루미와 대화**를 누르고 **밖에 조금 나가볼까 해요**를 고른다.
2. **동네로 나가기**를 누른다. 8개 장소 표식(모바일은 장소 목록) 중 **공원**을 선택한다.
3. **공원 입구로 이동**을 누른 뒤 왼쪽 방향 버튼을 두 번 누른다. 방향키·WASD로 직접 걸어갈 수도 있다.
4. 보상 안내에서 **내 방에서 보상 보기**를 누른다. 화분이 추가된 방을 확인하고 새로고침한다.
5. **처음부터**를 누르면 로컬 시연 상태가 초기화된다.

## 동작 범위

- 24×24 논리 타일의 코드 기반 아이소메트릭 동네, 방, NPC 6명, 벚꽃·분수·강과 다리·버스
- 8개 장소 버튼과 간단한 소개, 현재 위치를 반영하는 접이식 미니맵
- 5개 여정 카드와 실제 진행 상태를 반영하는 하단 단계 표시
- 루미의 고정 선택지 대화, 공원 도착 미션 1개, 화분 보상과 `localStorage` 재진입
- 낮/저녁, 이동·충돌, 키보드/터치 버튼, 모달 Esc·포커스 처리, 움직임 감소 설정

실제 AI 응답, 상담·신청·취업 서비스, 서버 저장, 위험 판정, 실제 보상은 없다. `agentAdapter.js`는 이후 연동을 위한 목업 경계다. [구현·검증 기록](../../docs/experiments/EXP-003_Showcase_UIUX_v0.2.md)을 참고한다.
