# EXP-005 × 3D 소셜 월드 점검

기존 `social_world/app/`의 마을에서 루미(`psych`)·코코·하루 대화를 EXP-005로 연결하는 로컬 점검 화면이다. 마을 소스와 배포용 HTML은 수정하지 않고, 이 서버가 HTML/JS를 제공할 때만 대화 진입을 연결한다. 다른 실험은 복사하지 않는다.

마을은 기존 `app/tests/ui_test.py`의 메모리 Supabase 대역과 가상 주민으로 시작한다. 온보딩을 완료한 가상 주민이므로 마을의 8문항 설문과 EXP-005의 두 항목 사전조사가 통합됐다는 뜻은 아니다. 외부 DB 연결은 브라우저 CSP로도 차단한다. 게임 데이터·추천 미션은 가상 데이터이고, 에이전트의 활동 카드는 실제 게임 미션이나 보상으로 전환하지 않는다.

## 실행

이미 생성된 화면과 Python 의존성이 있으면 `integration/run-demo.ps1`로 두 서버를 시작한다. 종료는 `integration/stop-demo.ps1`이다. 기본 포트 8005·8015가 사용 중이면 다른 프로세스를 종료하지 않고 실행을 멈춘다. 아래는 수동 설치·생성·실행 절차다.

Python·프런트엔드 패키지를 설치한 후 `experiments/exp005/`에서 실행한다. 기본 설정은 점검용 demo다.

```powershell
# 프런트엔드 설치·생성 (최초 또는 코드 변경 시)
cd frontend
npm ci
npm run build -- --base=/agent/
cd ..

# 터미널 1: 에이전트 서버
cd backend
$env:IEUM_MODE = 'demo'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8005 --no-access-log

# 터미널 2: exp005 폴더에서 마을 점검 서버
python integration/preview_server.py --port 8015 --backend-port 8005
```

브라우저에서 `http://127.0.0.1:8015/world/app/`에 접속한다. 이 실행은 기존 마을에 쓰던 Three.js CDN 연결이 필요하다. API·마을·대화창을 같은 출처로 제공하므로 기존 FastAPI CORS 설정을 확대하지 않는다.

## 점검 순서

1. 마을의 루미 대화 또는 왼쪽 아래 루미 점검 버튼 → 처리 동의 → 대화 시작.
2. 편한 도움 고르기 → 작은 활동 선호 → 혼자·실내 조건 → 활동 카드·상태 확인.
3. 마을로 돌아가기 → 코코 또는 하루. 대화 세션은 유지되고 NPC 표현만 바뀐다.
4. 정보 도움은 자료 미연결 안내인지 확인. 실제 조회·신청을 수행하지 않는다.
5. 가상 Safety 문장 → 맥락 확인 → 활동 요청 시 확인 유지 → 명시적 맥락 답변 후 복귀 확인.
6. 건너뛰기·질문 그만하기·선호 정정·대화 종료·삭제 확인.

`마을로 돌아가기`는 창만 숨긴다. 서버 삭제는 대화창의 `대화 종료·삭제`를 사용한다. 새로고침 시 화면 토큰을 잃을 수 있고 서버 세션은 생성 후 기본 30분까지 남을 수 있다.

현재 실행은 고정 응답과 Safety 초안 규칙의 연결 확인이다. 실제 모델 상담 품질, 상세 페르소나, 운영 DB, 정책 검색, 실제 상담사 인계는 검증 범위에 포함되지 않는다.
