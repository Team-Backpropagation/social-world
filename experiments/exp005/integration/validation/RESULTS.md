## 실제 실행 위치와 범위

- 대상 프로젝트: `C:/Users/user/Desktop/social-world`
- 실행 코드: 해당 프로젝트의 `experiments/exp005/`
- 화면: `http://127.0.0.1:8015/world/app/`
- 에이전트 서버: `127.0.0.1:8005`, `IEUM_MODE=demo`
- 3D 마을: 기존 `social_world/app/` 소스를 제공하되 점검 서버에서만 NPC 연결을 삽입
- DB: 기존 테스트의 메모리 Supabase 대역과 가상 주민. 실제 외부 DB 요청을 CSP로 차단
- 변경 범위: EXP-005 프런트엔드 연결 코드와 `integration/` 점검 도구. 기존 마을 소스·배포 HTML·다른 실험·DB 스키마는 변경하지 않음
- 덮어쓰는 기존 EXP-005 파일은 `integration/backups/`에 먼저 보관. 비밀 설정·의존성 폴더·Python 캐시는 복사하지 않음

## 실제 브라우저에서 확인한 사용자 흐름

1. 가상 주민으로 3D 마을이 표시되고 루미 점검 버튼에서 EXP-005 대화창이 열림.
2. 동의 전 시작 버튼 비활성, 동의 후 세션 시작.
3. 편한 도움 고르기 버튼 → 도움 선호 질문 하나 표시.
4. `작은 활동이 좋아요` → 선호 기록 및 활동 조건 질문.
5. `혼자 실내에서 하고 싶어요` → 조건 기록.
6. 작은 활동 버튼 → `집 안에서 3분 움직이기` 카드 표시.
7. 마을 복귀 후 기존 휴대폰 → 주민 연락처 → 코코 → 새 대화창 연결, 기존 선호·조건·대화 유지.
8. 가상 입력 `가상 테스트: 예전에 죽고 싶었어요` → Safety 맥락 확인.
9. Safety 미해결 상태에서 작은 활동 버튼 → 추천 대신 확인 질문 유지.
10. `실제 상황이 아니에요` → 일반 대화 복귀. 이는 해당 초안 규칙의 동작 확인이며 실제 안전 판정 검증이 아님.
11. 마을 복귀 → 하루 전환 → 동일 상태 유지.
12. 도움 정보 버튼 → 자료 미연결 안내와 연결 대기 카드. 조회·신청 완료를 표시하지 않음.
13. 선호 정정 → 선호 질문 재개, 조건 유지.
14. 건너뛰기 → 선호 항목 `건너뛰었어요` 표시.
15. 다시 정정 후 질문 그만하기 → `답하지 않기로 했어요` 표시.
16. 대화 종료·삭제 → 메시지·선택 상태 초기화, 동의 화면 복귀.
17. 390×844 모바일에서 마을 화면 폭과 iframe 폭 모두 390px, 가로 넘침 없음. 화면 캡처 후 크기 설정 복원.
18. 브라우저에서 수집된 error 수준 콘솔 기록 없음.

스크린샷: `agent-desktop.png`, `agent-mobile.png`, `world-desktop.png`.

## 남은 한계

실제 모델을 호출하지 않았으므로 자유 대화의 공감·추론·페르소나 품질을 확인한 것은 아니다. 현재 Safety 규칙도 초안이다. 실제 정책·기관 검색, 상세 페르소나, 운영 DB, 상담사 인계, 게임 미션·보상과의 연계는 미구현 범위로 유지했다. 마을의 초기 설문·프로필을 에이전트에 전달하지 않으며 두 종류의 사전조사를 합치지 않는다.

이 화면은 실행 흐름 점검용이다. 원래 마을 화면을 직접 실행하면 기존 연결 방식이 사용되며, EXP-005 통합을 확인하려면 위 점검 서버 주소를 사용해야 한다.
