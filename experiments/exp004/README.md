# EXP-004 — 첨부 이미지 충실형 Showcase v0.1

**개인 디자인 실험 / 팀 미확정.** 기존 [EXP-003](../exp003/README.md) 화면은 그대로 보존한다.

## 바로 보기

- [단독 HTML](showcase-image-faithful.html): 그림, CSS, JavaScript가 한 파일에 포함되어 있다. 브라우저에서 파일을 열어 사용할 수 있다.
- [편집용 HTML](index.html): 같은 화면을 구성하며 같은 폴더의 `reference.png`를 읽는다.
- 생성: PowerShell에서 `./build-standalone.ps1` 실행.

로컬 서버로 편집용 화면을 보려면 저장소 루트에서 `python -m http.server 5174 --bind 127.0.0.1 --directory experiments/exp004`을 실행한 뒤 `http://127.0.0.1:5174/index.html`을 연다. 서버가 계속 실행 중이라고 가정하지 않는다.

## 동작

첨부된 1536×1024 이미지를 원래 화면의 시각 레이어로 쓰고, 장소 8곳·미니맵·5개 여정 카드·하단 단계에 HTML 버튼을 겹쳤다. 첫 화면은 참고 이미지의 글자와 그림을 그대로 보여 준다. 장소 설명, 루미의 고정 선택지, 공원 정리 5회, 화분 보상은 팝업으로 시연한다. 진행 상태는 이 시제품 전용 `localStorage` 키에 저장된다. 모바일에서는 그림을 가로로 살펴보고 빠른 조작 버튼을 사용할 수 있다.

## 범위

이미지 속 건물과 글자는 아직 독립된 코드 요소가 아니다. 미션 진행 수치와 보상 변화는 팝업에서 바뀌며 배경 그림은 정적이다. 기관 신청·실제 AI 상담·지역 데이터 연동은 없다. 자세한 판단과 확인 결과는 [실험 기록](../../docs/experiments/EXP-004_이미지_충실형_Showcase_v0.1.md)에 남겼다.
