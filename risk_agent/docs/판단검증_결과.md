## 1. 무엇을 바꿨나

| | 전 (분위수 5단계) | 후 (4단계 상태) |
|---|---|---|
| 질문 | 다른 집단보다 나쁜가? | **자기 평소보다 나빠졌나?** |
| 등급/상태 | 점수를 줄 세워 5칸에 똑같이 나눔 → 상위 20%는 항상 "위험" | 확인권장 / 변화관찰 / 평소범위 / 판단보류. 기준을 넘은 집단이 없으면 0개 |
| 명절 반응 | 같은 지역 집단끼리 z → 누군가는 늘 "무반응" | 명절 동조도 β(지역이 움직인 만큼 따라 움직였나) |
| 대화 신호 | 집단끼리 z → 누군가는 늘 "높음" | 심각도 절대 기준(루미와 같은 0.45/0.8) |
| 계절·날씨 | 반영 안 함 | 같은 지역 다른 집단의 공통 변화를 빼고 봄 |
| 미래 데이터 | 29일 **중심** 창(뒤 14일 참조), 통신 산포에 평가 기간 포함 | 판정 신호는 그날까지의 자료만. 중심 창은 `--mode retrospective`(사후 분석)에만 |
| 통신(월 6점) | 가중치 0.20으로 합산 | 배경 신호 — 혼자서는 확인권장이 안 됨 |
| 검증 | 기본 1벌, 재현율만 성공 조건 | 시나리오 9종 × seed 20개, 조정용·평가용 seed 분리, 오탐률도 성공 조건 |

판정 기준값(`config.JUDGMENT`)은 **조정용 seed 1~10**으로만 골랐고, 아래 성적은 그 뒤 한 번도 조정에 쓰지 않은 **평가용 seed 101~120**으로 냈다.

"경고" = 전: Lv.3 이상 / 후: 확인권장

정밀도(경고 중 진짜): 전 33~40% → 후 경고가 나온 모든 시나리오에서 100%.

### 읽는 법
- **전**: 무슨 데이터를 넣어도 경고가 약 14개였다. 재현율이 높아 보였던 이유는 24개 중 14개에 늘 경고를 붙였기 때문이다.
- **후**: 위험을 심지 않으면 경고 0개, 하루·1주짜리 급감이나 지역 전체 감소에도 경고하지 않는다.
- **S2 중·약에서 재현율이 크게 떨어진다** — 약한 변화는 평소 흔들림과 구분되지 않는다. 숨기지 말고 "감지 한계"로 보고한다(4절).
- **S5 재현율 97.5%** — 심은 모양을 그대로 찾는 순환 검증만이 아니라, 다른 모양의 위험에도 작동한다.

**구조적 저활동형을 못 찾는 것은 설계상 한계다.** "원래부터 낮은 평탄선"은 자기 평소와 비교하면 변화가 없다.
통신 유동인구의 완만한 하락(월 2.8%)은 월 6점 자료에서 잡음과 크기가 비슷해, 통신만으로는 확인권장을 내지 않도록 했다.
보고서에는 **"변화 없음 ≠ 고립 없음"**을 한계로 적고, 외부 배경자료(1인가구 비율 등)를 정적 위험층으로 두는 안을 Open Item으로 둔다.

## 5. 탐지 한계(MDE) — 결제가 몇 % 줄어야 확인권장이 뜨나

`mde.py`가 집단 하나에만 감소를 넣어 보고, 처음 확인권장이 뜨는 감소 폭을 찾는다(다른 집단은 그대로라 지역 공통 차감이 작동).

합성 청년 8개 시연(평소 하루 흔들림 약 9.7%):

| 지속 기간 | 확인권장이 뜨는 감소 폭 |
|---|---|
| 3주 | 대부분 30% 넘게 줄어야 |
| 5주 | 15~30% |
| eval 전체(약 7.5주) | 10~20% |

> **실제 청년 데이터로 다시 재야 하는 숫자다.** 원자료가 있는 PC에서
> `python mde.py --youth ../data_preprocessing/clean/youth_master_daily.csv` 를 실행해 이 표를 갱신할 것.
> 보고서 문장 예: "이 모니터는 집단 결제가 평소보다 ○% 이상 ○주 이어지면 감지한다(그보다 작은 변화는 평소 흔들림과 구분하지 않는다)."

## 6. 판정 기준 (`config.JUDGMENT`)

| 신호 | 값의 뜻 | 관찰(변화관찰) | 확인(확인권장) |
|---|---|---|---|
| 카드 `trigger_z` | eval 수준이 평소 하루 흔들림의 몇 배 낮아졌나(지역 공통 변화 차감) | ≥ 1.0 | ≥ 1.5 **그리고** 기준 넘은 주 ≥ 3 |
| 통신 `baseline_z` | 이후 달 수준이 평소 월 흔들림의 몇 배 낮아졌나(지역 공통 차감) | ≥ 1.5 이고 이후 달 모두 | ≥ 2.0 **그리고 다른 신호도 관찰 이상**(혼자서는 안 됨) |
| 명절 `event_beta` | 지역이 움직인 만큼 따라 움직인 정도(1=같이, 0=무반응) | ≤ 0.6 | ≤ 0.35 **그리고** 판정 가능한 명절 2개 이상 모두 ≤ 0.6 |
| 대화 `micro_severity` | 심리상담 대화 평균 심각도(0~1) | ≥ 0.45 | ≥ 0.8 **또는** 최근 3개월 중 2개월 ≥ 0.45 |

- 평소 하루 흔들림 = baseline 안에서 그 무렵 수준(29일 중앙값)에서 하루하루 벗어난 정도. baseline 전체 평균에서 잰 표준편차는 baseline 안의 완만한 추세까지 흔들림으로 잡아 기준을 부풀렸다(조정 단계에서 소비 위축형을 놓친 원인).
- 통신 월 흔들림은 집단 하나의 4개 달로는 불안정해서, 같은 지역 집단들의 변동계수 중앙값을 쓴다(줄 세우기가 아니라 '보통 흔들리는 폭' 추정용).
- 판정 가능한 명절 = β의 표준오차가 0.35 이하인 구간. 하루짜리 광복절은 지역 움직임이 작아 보통 빠진다.
- 사후에 데이터로 찾은 7/16~17은 명절 판정에 쓰지 않는다(`EVENT_PERIODS[...]["calendar"] = False`).

### 조정 과정 기록 (조정용 seed 1~10)
1. 첫 시도: 정상 경고 1.4/회 — 전부 통신 신호. 월 6점이라 잡음과 신호 크기가 비슷 → 통신은 배경 신호로(혼자 확인권장 불가)
2. 소비 위축형이 확인 기준 바로 아래(z 1.36~1.47)에서 놓침 — 흔들림을 baseline 전체 표준편차로 재 추세가 섞인 탓 → 그 무렵 수준 대비 흔들림으로 교체
3. 정상에 변화관찰이 4.6/회로 많음 — 대부분 통신 1.0 → 통신 관찰 기준 1.5 + 이후 달 모두 조건

## 7. 한계

- **합성 데이터 검증이다.** 실제 고립 정답이 없어 실제 판별 정확도는 알 수 없다. S5(독립 생성)로 순환성을 줄였지만 없애지는 못한다.
- 원래부터 활동이 낮고 변화가 없는 집단은 찾지 못한다(3절).
- 약한 변화(효과 크기 중·약)는 대부분 놓친다. 감지 한계를 실제 데이터로 재서 사양으로 밝힌다(5절).
- 명절 무반응은 명절이 두 번 지나야 확인권장이 된다(4절).
- 대화 신호의 표본 기준은 아직 **세션 수**다. 실제 고유 사용자 수 기준·합성 배경 분리는 별도 작업(실행계획 작업 2).
- 지역 공통 차감은 같은 지역에 다른 집단이 2개 이상 있어야 작동한다(청년 모드는 지역당 4개라 충족).
