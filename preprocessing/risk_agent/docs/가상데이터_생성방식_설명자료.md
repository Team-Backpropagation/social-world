# 가상데이터 생성 방식 설명자료

> 대회 규칙(주제설명자료 260907 p.10)의 "가상데이터 생성 시 생성 방식에 대한 설명자료 제출 필수" 대응 문서.
> 생성 코드: `risk_agent/personas.py`, `synth_macro.py`, `synth_micro.py` (이 문서와 코드가 어긋나면 코드가 기준이다)
> 작성 2026-09-23

## 1. 왜 가상데이터를 쓰는가

위험 탐지 에이전트(통합기획서 6-6)는 거시 신호(통신·카드)와 미시 신호(소셜 월드 NPC 대화)를 함께 쓴다.
미시 신호는 서비스가 운영돼야 생기므로 프로토타입 단계에는 존재하지 않는다. 또한 파이프라인이
"실제로 위험 패턴을 읽어내는지"를 검증하려면 정답이 알려진 데이터가 필요하다. 이 두 가지 이유로
정답(원형)을 심어둔 가상데이터를 만들어 파이프라인 동작과 탐지 성능을 시연한다.

## 2. 대회 데이터와의 연결 — 페르소나의 출발점

통합기획서 4-4 원칙에 따라 페르소나는 **대회 데이터의 실제 구조와 실측치**에서 파생한다.

| 항목 | 사용한 실측치 | 출처 |
|---|---|---|
| 코호트 구조 | 강남구·춘천시 × 남녀 × 10세 단위 6구간 = 24개 | DB_테이블_정의서.md 4-1 |
| 통신 유동인구 기준 수준 | 2025년 7월 코호트별 유동인구(만 명) 24개 값 그대로 | 데이터_분석근거_정리.md 1-1 |
| 카드 결제건수 기준 수준 | 강남구 여성 20대 일평균 227,830건을 앵커로, 유동인구 비율의 0.6제곱으로 다른 코호트 스케일링 | 같은 문서 2절 |
| 정상 변동 크기 | 통신 변동계수 4.3%, 카드 9.7% | 같은 문서 6절 |
| 요일 효과 | 강남 금 1.07·일 0.84 / 춘천 토 1.16·일 0.92 등 요일 배율 | 같은 문서 12-1 |
| 명절 효과 | 공휴일에 강남 총량 하락·춘천 상승(이동성 이벤트), 추석 당일이 최대 | 같은 문서 4·12-4 |
| 이벤트 구간 | 7/16~17, 8/15, 10/3~9, 12/24~31 (18일) | 같은 문서 12-7 |

즉 "정상 코호트"의 가상데이터는 실측 수준·실측 변동폭·실측 요일/명절 패턴을 재현한 것이고,
여기에 아래 원형 효과만 추가로 얹는다.

## 3. 원형(archetype) — 심어둔 정답

24개 중 6개 코호트에 고립 가설별 원형을 배정했다. 나머지 18개는 정상(잡음만 존재)이다.
원형은 통합기획서 10-1 재정의 축과 데이터_분석근거_정리.md 10절 가설에서 가져왔다.

| 원형 | 가설 | 데이터에 넣은 효과 | 배정 코호트 |
|---|---|---|---|
| 이벤트 무반응형 | H-A | 명절·이벤트일에 지역 전체 효과의 12%만 반영(거의 반응 없음) | 춘천 남 40대, 춘천 여 30대 |
| 선택적 소비 위축형 | H-B | 카드 결제건수가 7/1 대비 12/31에 65% 수준까지 선형 감소 | 강남 남 50대, 강남 남 20대 |
| 구조적 저활동형 | H-C | 통신 유동인구가 매월 2.8%씩 감소, 카드 수준 85%로 고정 | 춘천 여 60대이상 |
| 미시신호형 | — | 심리상담 심각도 0.28→0.73, 세션당 위험키워드 0.9→3.0으로 점진 상승. 거시 데이터는 정상 | 강남 여 20대 |

배정 원칙: 고령 전용 현상으로 보이지 않도록 청년 코호트(20·30대)에도 원형을 넣었고, 이상 코호트가
소수만 섞인 현실적인 분포를 흉내 내기 위해 전체의 1/4만 배정했다. **파이프라인은 이 라벨을 보지 않는다.**
라벨은 `validate.py`의 채점에만 쓴다.

## 4. 미시 데이터(소셜 월드) 생성 규칙

- 대상: 20·30대 코호트 8개만(서비스 대상 한정, 통합기획서 7-1). 나머지 16개는 미시 데이터 없음
- 단위: 처음부터 **코호트×월 집계**로만 생성한다. 가상의 개인이나 개인 단위 대화를 만들지 않는다
  (`npc_chat_metrics`에 user_id가 없다는 설계 원칙과 일치)
- 월 세션 수: 강남 20대 평균 9, 30대 6 / 춘천은 각각 3을 뺀 값, 표준편차 35%
- 세션 수 5건 미만인 코호트는 파이프라인에서 미시 신호를 null로 처리(k-익명성) — 이번 실행에서는 춘천 남녀 30대 2개가 이에 해당
- 위험 키워드·심각도는 수치 지표만 생성. 대화 원문은 생성하지 않았다

## 5. 재현성

- 전체 시드 `RNG_SEED = 20260923`, 코호트·데이터종류별 시드는 `zlib.crc32("종류|코호트ID") XOR RNG_SEED`
- 파이썬 기본 `hash()`는 실행할 때마다 값이 바뀌어 재현이 안 되므로 쓰지 않는다
- 같은 코드를 여러 번 실행해 `risk_scores.csv`가 바이트 단위로 동일함을 확인했다

## 6. 검증 결과 — 심어둔 정답을 되찾는가

| 항목 | 결과 |
|---|---|
| 원형 6개 중 주의(Lv.3) 이상 탐지 | 6/6 |
| 주 원인(가장 크게 기여한 지표)이 원형과 일치 | 6/6 |
| 위험(Lv.5) 5개 중 원형 코호트 | 3/5 |
| 정상 18개 중 Lv.3 이상으로 오른 수 | 8/18 |

오탐 8개는 5단계를 분위수로 나누는 방식 때문에 생긴다(상위 60%가 항상 Lv.3 이상). 파이프라인은
이들 중 6개를 "뚜렷한 단일 원인 없음 — 오탐 가능성 검토 필요"로 따로 표시하고 복지자원을 매칭하지 않는다.
나머지 2개(강남 남 60대이상, 춘천 남 60대이상)는 잡음만으로 그럴듯한 원인(이벤트 무반응형, 복합형)이 붙어
Lv.5까지 올라갔다 — 잡음이 원형처럼 보일 수 있다는 뜻이므로, 실 데이터에서는 두 산출 주기 연속 확인 같은
안정성 조건을 두는 것을 권장한다.

## 7. 한계

- 이 검증은 **내적 타당성**(우리가 심은 패턴을 우리 로직이 읽는가)만 보여준다. 실제 고립 위험을 맞히는지는
  실 데이터 적용 후 KOSIS 고독사 통계 대조로 확인해야 한다
- 원형 효과의 크기(예: 65%까지 감소)는 시연을 위해 정한 값이며, 실제 고립 코호트가 이 정도로 뚜렷한
  신호를 낸다는 근거는 없다. 실제 신호가 더 약하면 탐지율은 떨어진다
- 업종 구성(엔트로피) 데이터는 생성하지 않았다. H-A는 현재 총량 반응으로만 측정된다

## 8. 시연용 합성 배경 — Supabase 순환 모드 (2026-09-23 추가)

소셜 월드 ↔ 위험 탐지 에이전트 전체 순환(`run_pipeline.py --youth --supabase`)을 시연하면 실제 사용자가
몇 명뿐이라 코호트당 세션 수가 k-익명성 기준(5건)에 못 미친다. 기준을 낮추는 대신 합성 배경을 깔아 기준은 유지한다.

| 항목 | 규칙 |
|---|---|
| 대상 | 실제 청년 데이터의 8개 코호트(강남·춘천 × 남녀 × 20·30대) |
| 기간 | 실행 시점 기준 최근 6개월 (예: 2026-04 ~ 2026-09) |
| 원형 | **없음** — 8개 모두 평상시 수준. 시연자의 실제 대화만이 자기 코호트 신호를 움직이게 하려는 의도 |
| 월 세션 수 | 평균 10, 표준편차 2, 최소 6 (k=5 이상 보장) |
| 심각도 | 평균 0.28, 표준편차 0.04 (0~1) |
| 위험 키워드 | 세션당 0.9건 + 잡음(표준편차 1) |
| 키워드 주제 구성 | 무기력 34% · 소외감 14% · 대화상대없음 12% · 장기구직 12% · 사회적회피 10% · 생계부담 10% · 고립지속 8% (평상시 가벼운 대화 수준. 위기발화·장기고립 같은 무거운 주제는 배경에 넣지 않음) |
| 대화한 사람 수 | 합성 배경은 1세션 = 1명으로 간주(`user_count = session_count`) |
| 저장 위치 | `npc_chat_metrics`, `source='synthetic'` — 실제 대화 집계(`source='live'`)와 행 단위로 구분 |
| 결합 | 같은 코호트·월의 합성+실제를 합산, 심각도는 세션 수 가중평균 |
| 재현성 | 시드 `zlib.crc32("bg|코호트ID") XOR 20260923` |
| 코드 | `risk_agent/supabase_sync.py`의 `build_synthetic_background()` |

로컬 PostgreSQL+PostgREST로 검증한 결과, 이 배경 위에서 한 코호트에 무거운 선택지(심각도 0.8, 키워드 2개) 대화를
3건 더하면 그 코호트의 환류가 "심리상담 NPC 강조"로 바뀐다. 시연 효과가 합성 배경의 잡음 크기에 달려 있다는 점,
그리고 실서비스에서는 합성 배경 없이 실제 이용자 수로 k-익명성을 채워야 한다는 점을 함께 밝힌다.
