# social_world — 시민용 소셜 월드

통합기획서 7장의 예방형 게임 웹서비스. 청년(20~30대)이 마을을 돌아다니며 NPC와 대화하고 미션·동아리에 참여한다.
대화에서 나온 신호는 코호트 단위로만 모여 위험 탐지 에이전트에 들어가고, 에이전트의 판단은 다시 이 화면의 추천으로 돌아온다.

| 버전 | 위치 | 용도 | 순환 연결 |
|---|---|---|---|
| **단일 HTML 데모** | `socialworld-demo.html` (원본은 `app/`) | 브리핑·시연용. 설치 없이 브라우저로 열면 팀 Supabase에 바로 붙는다 | ✅ |
| **React 프로토타입** | `react_app/` (Vite + React 19 + Supabase) | 본 개발의 출발점. 카카오 로그인·라우팅·화면 분리 | ❌ 아직 |

## 1. 단일 HTML 데모 (`socialworld-demo.html`)

실행: 파일을 브라우저로 연다 → **게스트로 체험하기** → 튜토리얼 → 광장.

> **2026-10-02부터 `socialworld-demo.html`은 자동 생성 파일이다.** 원본은 `app/`(엔진·앱·휴대폰 UI·스타일을 나눈 파일)이고
> `python social_world/app/bundle.py`로 다시 만든다. 데모를 고칠 때는 `app/`을 고친다 — 자세한 건 `app/README.md`.
> 같은 날 UI 담당 팀원의 PR #13(휴대폰·전체 지도·설정·코코 알림·효과음)을 합쳤다.

**튜토리얼 (2026-09-29, 설계 문서 `docs/planning/소셜월드_게임흐름_NPC_설계.md` 13절)**

1. 사전 설문 8문항 — 닉네임·지역·나이대·성별(필수), 분위기+색(필수), 관심사·해보고 싶은 것·요즘 하루(건너뛰기 가능)
2. 분위기·색으로 캐릭터 1차 생성 → 부위별 ◀▶로 직접 꾸미기
3. 3D 내 방 침대에서 깨어남 → 루미가 문을 두드리고 걸어 들어와 인사(대본형). "요즘" 답은 말투에만 쓰고 저장하지 않는다
4. 집 앞으로 나가 루미가 앞장서는 마을 8곳 도보 투어(금색 표시, "루미 따라가기" 자동 이동) → 마지막에 마을이장께 인사하면 첫 퀘스트 "광장 방문하기" 완료

**3D 마을 (2026-09-29)** — "이음 마을" 3D 컨셉 아티팩트의 장면(Three.js 0.149, CDN)을 옮겼다. WASD·방향키 이동, 땅을 누르면 그곳으로, 가까이서 E로 대화·입장, M으로 전체 지도. 오른쪽 아래 **나의 휴대폰**에서 동아리·미션·주민 연락처·설정(화질·키 바꾸기·미니맵 방향·효과음·로그아웃)을 쓴다. WebGL이 없는 기기는 안내 화면이 뜨고 미션방·동아리센터만 쓸 수 있다.

동쪽 '내 집'에 들어가면 내 방 — 캐릭터 꾸미기·루미 소개 다시 보기·밖으로 나가기.
팀 Supabase에 `database/03_world_update.sql`이 아직 없으면 기본 정보만 DB에 저장하고 캐릭터·관심사·가입목표는 그 브라우저에 보관한다(화면에 안내가 뜬다, 퀘스트 기록은 건너뜀). 03이 적용된 뒤 같은 브라우저로 처음 들어오면 보관해 둔 값이 DB로 자동으로 옮겨진다.
2026-09-30 이전 버전은 이 경우 관심사·가입목표를 어디에도 남기지 않고 버렸다 — 9/30 이전 테스트 가입자 11명의 관심사가 비어 있는 이유.

구현된 것:

- **3D 마을** — 광장·지원센터·미션방·동아리센터·게임방·카페·공원·내 집(내 방 실내). NPC 4종(정책추천·취업상담 창구, 루미, 마을이장)과 대본형 대화. 지원센터·카페·공원·게임방 안은 준비 중
- **나의 휴대폰·전체 지도** (PR #13 UI) — 동아리 목록·가입, 미션 시작·완료(DB), 주민 연락처(그 NPC 앞으로 이동해 대화), 전체 지도(M)로 순간이동, 설정(키 바꾸기 등, 이 브라우저에만 저장), 마을 입장 후 코코 알림 1회·효과음. 투어·방 튜토리얼 중엔 숨김
- **신호가 붙은 선택지** — 선택지마다 위험 키워드 태그와 0~1 심각도가 붙어 있다. 태그는 UCLA 외로움 척도·De Jong Gierveld 척도·서울시 고립은둔청년 실태조사 문항 주제를 풀어 쓴 10종이다
  (무기력, 소외감, 대화상대없음, 장기구직, 구직단념, 사회적회피, 생계부담, 고립지속, 장기고립, 위기발화)
- **대화 저장** — NPC 창을 닫을 때 한 번 이상 선택했으면 `npc_sessions`에 1행 저장(NPC 종류·태그·키워드 수·최대 심각도). **대화 원문은 저장하지 않는다**
- **위기 안내** — 심리상담 대본의 위기 선택지를 고르면 즉시 자살예방 상담전화 109·정신건강 상담전화 1577-0199·긴급 112/119를 안내하고,
  `report_crisis()`로 지역·시각·NPC 종류만 `escalations`에 남긴다(user_id 없음). 관리자 대시보드 상단 알림에 뜬다
- **포지셔닝 고지** — 심리상담 NPC는 "전문 상담사가 아니라 연결 도구"임을 대화창에 표시
- **개인화 환류** — 로그인 시 `cohort_feedback`에서 **자기 코호트 행만** 읽어(RLS) 광장에 추천 NPC 말풍선을 띄우고, 추천 미션을 위로 올려 "추천" 배지를 단다.
  위험 등급·점수는 이 표에 없으므로 시민 화면에 "당신의 집단은 위험"이 노출될 경로가 없다

키 관리: 파일 안의 `SUPABASE_ANON_KEY`는 브라우저용 publishable key라 공개돼도 RLS가 막는다. secret key는 이 파일에 절대 넣지 않는다.

## 2. React 프로토타입 (`react_app/`)

2026-09-22에 만든 본 개발용 코드베이스. 자세한 실행법은 `react_app/README.md`.

```bash
cd social_world/react_app
npm install
cp .env.example .env     # VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY 채우기
npm run dev
```

구현: SW-01 로그인(카카오 + 게스트), SW-02 온보딩, SW-03 광장(2D 탑다운), SW-06 미션방, SW-07 동아리방. NPC 3종은 분기형 스크립트 목업.
`npm run build` 오류 없음 확인(2026-09-22).
