## 바뀐 것
- **나무·덤불·텃밭 잎**: 반투명 잎 카드 → 둥글고 chunky한 low-poly 덩어리(각진 면이 보이는 flat shading)
- **풀**: 가는 풀잎 3.4만 개 → 넓적한 풀 뭉치 4,800개. 땅 얼룩 텍스처를 줄여 큰 색면 위주로
- **빛**: 노을빛 → 맑은 낮. 하늘은 연하늘, 환경광을 높이고 그림자를 부드럽게
- **후처리**: 틸트시프트는 유지, bloom·빛줄기(렌즈 플레어 느낌)·노을 톤·강한 비네트 제거
- **장소별 지붕색**: 지원센터 민트 / 미션방 코랄 / 동아리센터 라벤더 / 게임방 해바라기 / 카페 베리 / 내 집 하늘
- **모듈형 화분 6개**: 광장 가장자리, 길·가로등·벤치를 피한 자리에 (크기·회전·색을 조금씩 다르게)

## 그대로인 것
장소 좌표·건물 크기·문 위치, colliders/places/doors, NPC id, API, 튜토리얼·투어·대화, 9장면, 둥근 지평선 셰이더, 틸트시프트 구조, three.js r149. 외부 이미지 파일 없음.

## 확인
데모 사본으로 전체 자동 테스트(튜토리얼 → 8곳 도보 투어 → 이장 인사 → 루미 대화 → 자유 시점 → 모바일) 통과, 콘솔 오류 없음.

## 지붕·차양 수정 (2차)
- 삼각 막대를 통째로 얹던 지붕 → **박공벽(벽과 같은 색) + 두께 있는 경사 지붕판 2장 + 용마루**, 사방으로 처마가 나오게
- 지붕 크기를 건물 몸체 치수에서 계산 — 동아리센터·카페에서 벽이 지붕 밖으로 삐져나오던 문제 해결
- 동아리센터·카페·내 집은 정면이 박공(삼각형 벽)이 되도록 방향을 바꿈. 미션방은 옆으로 긴 지붕 유지
- 지원센터 지붕: 마름모로 비뚤어진 피라미드 → 건물 크기에 맞는 **직사각형 모임지붕**(처마 0.6, 띠 위에 딱 붙음, 처마 두께판). 원본 데모와 같은 코드
- 카페 간판이 지붕을 뚫고 나오던 것 → 정면 박공벽에 붙임
- 납작한 판 차양 → 벽에 붙어 비스듬히 내려오는 차양 + 반원 물결 끝단 (동아리센터·카페)
