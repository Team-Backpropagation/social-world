## 바뀐 것
- **카메라**: 대각선 45°에서 내려다보는 아이소메트릭 느낌 — 좁은 화각 + 먼 거리, 둥근 지평선 끔(평평한 판). WASD·자유 시점·↺ 시점은 그대로 동작
- **떠 있는 디오라마 판**: 바깥 들판을 없애고, 마을을 잔디 윗단 + 흙 두 층 단면의 판 위에 올림. 배경은 짙은 남보라
- **건물**: 크림 벽 + 짙은 갈색 **기와 지붕**(모든 지붕에 기와 무늬). 게임방 천막은 벽돌빨강·크림 줄무늬
- **나무**: 둥근 블록을 쌓은 라임빛 나무 / **덤불**: 짙은 초록 공 모양
- **길**: 네모난 베이지 **판석**을 두 줄로 깖. 광장은 원형 판석
- **농장**: 텃밭 → **밀 다발·건초 더미**, 마을 가장자리 밀밭 3곳, **닭장 + 울타리 마당 + 병아리 6·닭 2**(돌아다님), **헛간**(동쪽 끝). 건물 8채 = 지원센터·미션방·동아리센터·게임방·카페·내 집·닭장·헛간
- **바위**: 크림색 블록 바위 더미(뒤쪽 테라스), 강가 돌도 크림색
- **빛**: 화면 왼쪽 위에서 오는 따뜻한 햇빛, 오른쪽으로 떨어지는 부드러운 그림자. 빛줄기 제거, bloom 약하게

## 그대로인 것 / 확인
장소 좌표·건물 크기·문 위치, colliders/places/doors, NPC id, API, 튜토리얼·투어·대화, 캐릭터, 9장면, three.js r149. 외부 이미지·모델 파일 없음.
데모 사본으로 전체 자동 테스트 통과(기본 시점이 45°라 시점 되돌리기 검사만 그 각도 기준으로), 콘솔 오류 없음.

> 레퍼런스 이미지의 출처·라이선스가 확인되지 않아, 형태·색·구성 원리만 참고하고 특정 건물·간판 글자 등은 옮기지 않았어요.

## 지붕·차양 수정 (2차)
- 삼각 막대를 통째로 얹던 지붕 → **박공벽(벽과 같은 색) + 두께 있는 경사 지붕판 2장 + 용마루**, 사방으로 처마가 나오게
- 지붕 크기를 건물 몸체 치수에서 계산 — 동아리센터·카페에서 벽이 지붕 밖으로 삐져나오던 문제 해결
- 동아리센터·카페·내 집은 정면이 박공(삼각형 벽)이 되도록 방향을 바꿈. 미션방은 옆으로 긴 지붕 유지
- 지원센터 지붕: 마름모로 비뚤어진 피라미드 → 건물 크기에 맞는 **직사각형 모임지붕**(처마 0.6, 띠 위에 딱 붙음, 처마 두께판). 원본 데모와 같은 코드
- 카페 간판이 지붕을 뚫고 나오던 것 → 정면 박공벽에 붙임
- 납작한 판 차양 → 벽에 붙어 비스듬히 내려오는 차양 + 반원 물결 끝단 (동아리센터·카페)
- 닭장·헛간도 같은 박공지붕으로
