# 후보: Claude — Cartoon Village (구 Soft)

모서리가 둥근 네모 low-poly 마을에 **선명한 색 · 맑은 하늘 · 카툰 표현**을 입힌 후보예요. 캐릭터 모델은 그대로(툰 셰이딩·외곽선만 적용).

| 파일 | 설명 |
|---|---|
| `socialworld-demo_cartoon.html` | **데모 사본**: 로그인·튜토리얼·투어·대화 전체에 적용 (원본 데모는 그대로) |
| `concept_claude_cartoon.html` | 키트 후보: 9장면 비교·캡처용 |
| `Claude_Cartoon_<장면>.png` ×9, `Claude_Cartoon_9장면.png` | 기본 각도 캡처 |

## 형태 · 조경
- 나무·덤불·작물 잎: 모서리 둥근 네모 블록 2단 / 바위도 둥근 네모
- 풀: 삼각 풀잎 대신 낮고 둥근 풀 둔덕을 드문드문
- 작은 공원: 광장 가장자리 둥근 네모 생울타리 5개, 광장·연못 주변 네모 화분 5개
- 지붕: 박공지붕(박공벽 + 두께 있는 지붕판 + 용마루), 지원센터는 직사각형 모임지붕

## 색 · 날씨
- 캔디 톤 선명한 색 — 민트 지원센터 / 코랄 미션방 / 보라 동아리센터 / 오렌지 게임방 / 핑크 카페 / 파랑 내 집, 진한 초록 나무
- **맑고 푸른 하늘 + 뭉게구름 11개(천천히 흐름) + 만화풍 해(햇살 12줄)**
  - 기본 시점에서 하늘이 보이도록 카메라를 약 29°로 낮추고, 하늘을 가리던 뒤쪽 흙 언덕을 없앰(뒷줄 나무는 땅 위로)
  - 해·구름은 기본 시점 기준 화면 위쪽에 오도록 배치. 시점을 돌리면 구름은 사방에 있고 해는 북쪽 하늘에 있음
- 햇빛 세게 + 환경광 낮춰 또렷한 명암

## 뿌연 느낌 제거
- 안개를 멀리(110~260) 밀고 하늘색과 맞춤
- 화면 위아래 흐림(틸트시프트) 세기를 원래의 1/6 수준으로
- 대비 곡선 추가, 가장자리 어둡게 하기 거의 없앰, bloom·빛줄기 없음

## 카툰
- 모든 재질 3단 툰 셰이딩, 건물·나무·캐릭터에 진한 외곽선 (작은 부품·반투명·판 모양은 제외)

## 그대로인 것 / 확인
장소 좌표·건물 크기·문 위치, colliders/places/doors, NPC id, API, 튜토리얼·투어·대화, 9장면, three.js r149. 외부 이미지·모델 파일 없음.
데모 사본으로 전체 자동 테스트 통과, 콘솔 오류 없음.
