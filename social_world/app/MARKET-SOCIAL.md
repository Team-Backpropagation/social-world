## 반영한 내용

1. **은행 외벽 시계**: 은행 외벽과 어울리는 녹색 케이스·금빛 테두리·밝은 문자판에 시간 눈금과 숫자를 넣었다. 시침·분침은 두께가 있는 3D 모델이며, 브라우저가 읽는 사용자의 컴퓨터 현지 시간을 따른다. 초에 따라 분침이, 분·초에 따라 시침이 움직인다. 컴퓨터 시간이 바뀌거나 자정을 지나도 다음 갱신에 반영한다.
2. **시장 벤치**: 광장 일반 벤치 두 개는 등받이를 사이에 두고 양방향 좌석을 배치했다. 정류장 벤치는 한쪽 방향을 유지하면서 노란 표지판 옆으로 옮겼다. 버스 문 앞 보행 경로를 비웠다.
3. **은행 실내 벤치**: 카운터를 바라보게 돌렸다. 가운데 보행 통로는 유지한다.
4. **마을 정류장 벤치**: 동쪽 도로를 바라보게 돌리고, 회전한 위치에 맞춰 충돌 범위를 갱신했다.
5. **시장 채팅 UI**: 시장 광장에서 메시지를 입력하고 보내면 현재 닉네임과 함께 기록하고, 캐릭터 머리 위에 말풍선을 표시한다. 말풍선이 캐릭터 이동·시점을 따라가고 화면 밖으로 잘리지 않도록 맞췄다.

## 채팅 이용

PC에서는 시장 왼쪽 아래 채팅창이 기본으로 펼쳐진다. 모바일에서는 `시장 채팅`을 누르면 펼쳐진다. Enter로 입력란을 선택하고, 내용을 입력한 뒤 Enter 또는 보내기로 전송한다. Esc로 입력을 끝내면 이동할 수 있다.

입력 중에는 캐릭터 이동·지도·인벤토리·상호작용을 막는다. 한글 조합을 확정하는 Enter로 메시지를 성급하게 보내지 않는다. 모바일 가상 키보드가 올라오면 입력창을 키보드 위로 올린다. 도착 안내가 입력창을 가리지 않도록 위치를 조정했다.

채팅창은 시장 광장에만 표시한다. 은행·옷가게 실내, 버스 이동, 휴대폰·지도·대화창에서는 숨긴다. 말풍선은 5~9초 후 사라지고 시장을 벗어나면 바로 제거한다. 메시지는 80자까지, 현재 페이지의 최근 기록은 30개까지 유지한다.

**이번 구현은 현재 사용자의 입력과 말풍선을 확인하는 UI 데모다.** 기록은 현재 페이지 메모리에만 유지하며 로그아웃·새로고침으로 초기화한다. 다른 사용자에게 메시지를 전송하는 통신 기능은 후속 구현 범위다.

## 검증

- 시계·벤치·채팅 UI: PC·모바일 × 소스·한 파일 데모, **146개 항목 통과**. 서울·로스앤젤레스 시간대에서 컴퓨터 현지 시각, 자정·시각 변경과 3D 바늘 각도를 검증했다. 시장 한정 표시, 머리 위 말풍선 따라가기·소멸, 입력 중 이동 차단, 한글 조합, 문자 그대로 표시, 80자·30개 한도, 모바일 키보드 위 배치를 확인했다.
- 기존 버스·시장·시설 출입: **164개 항목 통과**. 벤치 이동 뒤에도 왕복 승하차가 차체를 관통하지 않고 우회하며 정상적으로 도착한다.
- 별도 차량 충돌·글꼴 로딩: **26개 항목 통과**.
- 기존 기능: 낚시 135개, 휴대폰·지도·설정 80개, 코코 34개, 마을이장 42개 항목 통과.

- 브라우저 검증은 설치된 Chrome·로컬 three.js 0.149.0과 데모가 제공하는 경량 장면으로 실행했다. 기존 테스트 소스와 검증 항목은 유지하고 실행 환경에서 경량 모드를 선택했다. UI·시간·좌표·충돌 규칙은 같은 구현을 사용한다.
- JavaScript 문법과 생성된 HTML 일치, ZIP 무결성, 효과음과 앱 밖 파일 보존을 확인했다.
