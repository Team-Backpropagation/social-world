확인한 기준: `C:/Users/user/Desktop/social-world/social_world/app/world-engine.js`의 `person()`과 `LUMI_LOOK`, `NPC_LOOK`; EXP-005 검증 화면 `world-desktop.png`; 사용자 첨부 페르소나 v0.1 문서.
